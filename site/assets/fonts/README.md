# Local type assets

Self-hosted WOFF2 files used by the ikat GitHub Pages site:

- Barlow Condensed 600/700 — display headings and part labels.
- Source Sans 3 variable — body text and navigation.
- IBM Plex Mono 400 — commands, code, and measurement labels only.

Each family’s SIL Open Font License is included beside the font file. The fonts are served locally; the page does not request fonts from a third-party CDN.
