Keep every figure inside the paper.

Ikat turns Markdown, flowcharts, and plot data into LaTeX and PDF. Diagrams and charts stay editable as TeX-native source that uses the paper’s own fonts.

Quick start

Source build
macOS / Linux 
git clone https://github.com/opticsWolf/ikat.git
cd ikat
python3 -m venv .venv
source .venv/bin/activate
python -m pip install maturin pytest
maturin develop
python -m pytest tests/
ikat build site/hello-paper.md --outdir out --no-pdf
Windows PowerShell 
git clone https://github.com/opticsWolf/ikat.git
cd ikat
py -3 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install maturin pytest
maturin develop
python -m pytest tests/
ikat build site/hello-paper.md --outdir out --no-pdf

For a PDF, install a TeX distribution and rerun the last command without --no-pdf. Add mcp>=1,<2 if you also want ikat’s optional MCP server.

One pipeline. Paper-native output.

Rust owns parsing, layout, and figure code generation. Python carries document strings and drives the tools.

INPUTMarkdown
Headings, tables, citations, code, footnotes, math, and Unicode become a complete LaTeX document.
DIAGRAMSMermaid → TikZ
A strict graph TD / graph LR flowchart subset, laid out deterministically. Unsupported syntax fails fast.
PLOTSData → pgfplots
Bar and line plots are emitted directly as TeX, including whiskers, log axes, and collision-aware legend placement.
LAYOUTFloats + templates
Configure width, column span, placement, document heads, and whole-document skeletons without surrendering the source.

TeX boundary: ikat weave writes TeX without TeX installed. To compile a PDF, use a local pdflatex installation; a bibliography also needs bibtex.

One core. Ready for agents.

Use the same Rust-backed pipeline from code, a shell, or an agent connection. Add the repository skill when an LLM needs ikat-specific workflow guidance.

APIPython
Build documents and emit diagrams, plots, and TeX package requirements in process.
MCPAgent tools
Optional stdio server for weaving, TikZ/pgfplots, package checks, templates, and skeletons. PDF compilation stays in the CLI.
CLIShell
Script builds, TeX-only output, package checks, standalone figure emitters, templates, and skeletons.
SKILLAgent guidance
The ikat Agent Skill helps agents choose an interface and respect syntax and build boundaries.
